# Password-Generator
Simple Password Generator

A lightweight Python command-line utility that generates strong, random passwords using custom character pools.

## Features
- Prompts the user to specify the desired password length.
- Generates random combinations of uppercase letters, lowercase letters, digits, and special symbols.
- Built using Python's native `random` module.

## How to Run
1. Make sure you have Python 3 installed.
2. Run the script via terminal:
   ```bash
   python password_gen.py
